Everything you need, nothing you don't

Built lean, built fast. Silly strips away the bloat so you can focus on your API.

👤

Multi-Profile

Switch between workspaces instantly with Arc-style profile switching. Each profile keeps its own collections, headers, and env.

⚡

GPU Accelerated

Powered by GPUI — the same rendering engine that drives Zed editor. Renders at 120fps even on huge JSON payloads.

🔐

Auth Support

Bearer tokens, API keys, Basic Auth — all handled natively. Store credentials per-profile and never paste them again.

📁

Collections & Folders

Organise requests into nested folders. Drag-and-drop reordering with persistent state across sessions.

🌍

Environment Variables

Define variables per profile and reference them with {{variable}} syntax in any field.

📜

Request History

Every request you send is automatically saved. Search, replay, or diff responses from previous runs.
